- 一句介绍，或列表页那张 920×350 的图
- 句末固定写「赞助」
- 整条可点，在新页面打开广告主给出的地址
- 链接使用 `rel="sponsored nofollow"`

介绍 40 个字以内。推荐站点这一列不写介绍，只写站名和「赞助」。
