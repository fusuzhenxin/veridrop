# 广告投放管理

后台「经营 → 广告」管理投放档期和状态；流量分析仍在「经营 → 流量」。

## 状态与档期

- 所有日期以北京时间计算，开始日包含，到期日 00:00 自动撤下。
- 暂停优先显示为「已暂停」；未暂停的广告按日期分为在投、待开始、已到期。
- 「即将到期」是在投广告的子集：未来 7 天内到期，包含第 7 天。
- 状态总览和今日广告位余量始终统计全部广告，不随列表搜索和分页缩小。
- 物理位置筛选包含套餐，如「列表页顶部」会包含列表页加页脚、全包。
- 搜索匹配名称或完整跳转链接，`%`、`_` 作为普通字符处理。

## 广告位容量

左右角标最多 2 条，列表页顶部最多 4 条，页脚不限。套餐同时占用各自的物理位置；暂停广告不预留位置。

`GET /api/ads/availability?slot=full&start=2026-11-11&end=2026-11-18&exclude_id=1`

此接口需管理员登录，只检查不预订。返回每个位置在整个档期中的占位峰值、最小余量及第一个已满时段。编辑时排除当前广告；前后档期相接不算重叠。

保存和恢复广告使用同一容量检查，不能仅凭先前预览结果突破限制。`POST /api/ads/{id}/state` 仅接收布尔值 `paused`，从数据库读取最新内容后变更状态，不覆盖列表加载后更新的文案、链接与档期。

列表中的曝光、点击、点击率仍是累计广告位原始计数，含历史未分类流量；过滤、页面和位置归因请使用流量页。

## 验证

```powershell
python -m unittest discover -s server -p test_ad_management.py
python -m unittest discover -s server -p test_ops.py
npm run build --prefix admin
node scripts/ads-ui.test.mjs
```

浏览器回归通过 `PLAYWRIGHT_MODULE` 指定已有 Playwright，默认访问 `http://127.0.0.1:5180`，可用 `ADS_ADMIN_URL` 修改；`ADS_QA_OUTPUT` 设置截图目录。所有接口在测试浏览器中被示例数据拦截，不修改真实广告或计数。覆盖筛选、下拉框、分页、暂停恢复、空结果、失败重试、桌面/窄屏、冲突拦截、暂停保存和过期响应丢弃。

## 排期、效果报告与续费衔接

月排期入口 `/ad-calendar`，按物理广告位计算未来余量，待安排订单单列。订单的效果报告和明确确认后的投放更新详见 [广告订单台账](ad-orders.md)。报告按购买位置和档期统计，不将站内收录入口混作广告位交付。
