# 评测方法

维渡 AI 是第三方 AI 中转站目录。收录和名次不收费。本站不代收充值，也不证明官方原厂。

## 数据从哪来

| 内容 | 来源 |
| --- | --- |
| 站点在线率、延迟 | 目录探测。这是站点级记录。 |
| 输入价、输出价、缓存价 | 该站公开的价格接口，按对方公布的倍率公式换算。 |
| 公告 | 该站公开的公告接口。没有就不显示。 |
| 最低充值、支付、发票、退款 | 目录里已经记下的字段。没有的不补。 |
| 赞成、反对、点评 | 登录账户提交，其他人可以看见。 |

没有拿到的数字留空，不估一个分数。

## 评分

有人投票时，星级等于赞成除以赞成加反对，再乘以 5。评价条数等于赞成加反对。

没有投票、但目录里原来有评价时，沿用那些评价的星级。投票和评价都没有，显示暂无评分。

名次把原来的站和后收录的站放在一起。访问异常的排在最后。其余先比可用率，高的在前；可用率相同再比延迟，低的在前。没有探测数字的排在有数字的后面。投票不参与这个名次。

赞成和反对每人每站一票。再点一次同一边就是取消。

## 本站没有做的探测

纯度、单个模型的延迟、单个模型的在线率，都没有探测。

用户在浏览器里用自己的地址和 Key 做的检测，结果只留在那台浏览器，不能当成站内的纯度分。
