检测说明

自测会把 API Key 发到本站吗？
不会。请求从浏览器直接发到你填写的地址。Key 默认只留在当次页面，勾选后才写进这台浏览器。
糖果测试和鹈鹕骑车能证明模型是官方原厂吗？
不能。它们对照的是这一次调用的推理、画图和有没有改写输入输出。官方原厂要看服务端签名，不在这些题目里。
怎么看 API 中转有没有 GPT 降智？
先跑基础检测看接口通不通，再跑糖果测试和鹈鹕骑车。模型可以选 GPT-6 Astra。降智只根据这两项能力题，基础项不支持或网络失败不算降智。这不是官方鉴定。
糖果测试在测什么？
可以从 5、10、15、20 道里选题量。做到哪题展示哪题。跑完给出分数、对错、正确率和迷惑辨析、数量关系、约束求解、演绎四项得分。
鹈鹕骑车在测什么？
用一句固定提示词，让模型交回用 SVG 画的鹈鹕骑自行车 2D 动画 HTML。跑完可以在页面播放，也可以下载。速度滑杆不在提示词里。
基础检测没通过是不是降智？
不是。基础检测看协议、流式、上下文、工具和用量。不支持的记为跳过，不扣成降智。
模型名单里没有我的模型怎么办？
填好地址和 Key 后，会向你填写的接口读取模型列表。列表只留在这台浏览器，不经过本站。
